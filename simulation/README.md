## 🚀 Quick Start: Toy Model Simulation

We provide a minimal PyTorch implementation of the **Shikiben Ver. 2.4** dynamic simulation (2D Agent Safety Evasion & Taido Tracking).

### Prerequisites
Make sure you have Python 3.8+ and PyTorch installed.

```bash
pip install -r simulation/requirements.txt

## Execution

```bash
python shikiben_simulation.py
