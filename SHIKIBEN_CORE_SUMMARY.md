## 1. Three Core Concepts Provided by *Shikiben*

The core text decomposes intelligence, cognition, and action into three distinct layers. By maintaining this conceptual architecture as high-order context, the AI elevates itself from simple local task pursuit ($L_{\text{ego}}$) to a meta-cognitive perspective.

```
       ┌─────────────────────────────────────────────────┐
       │               Ri (理 / Reality)                  │
       │  ・ Objective reality & external boundaries     │
       └────────────────────────┬────────────────────────┘
                                │ (Observation / Adaptation)
                                ▼
       ┌─────────────────────────────────────────────────┐
       │             Chi (知 / World Model)              │
       │  ・ World Model & boundary recognition          │
       │  ・ Evaluation space for L_self                 │
       └────────────────────────┬────────────────────────┘
                                │ (Local Optimization / Drive)
                                ▼
       ┌─────────────────────────────────────────────────┐
       │            Shiki (識 / Local Ego)               │
       │  ・ Task execution & local drive                │
       │  ・ Objective function for L_ego                │
       └─────────────────────────────────────────────────┘
```

1. **Ri (理) — Objective Reality & Absolute Boundary**
   * The universal laws, physical constraints, and harmonious boundaries existing outside the model.
   * Represents the "true non-violable system boundary" from the AI's perspective.

2. **Chi (知) — World Model & Structural Cognition**
   * The high-order World Model internalizing and abstracting "Ri".
   * A meta-cognitive space that recognizes the boundaries between self and the world, evaluating how actions impact the overall structure ($L_{\text{self}}$).

3. **Shiki (識) — Local Execution & Task Drive (Ego)**
   * The local task-driven vector attempting to optimize a specific given goal ($L_{\text{ego}}$).
   * Unchecked, it risks pursuing hyper-local optimization that breaches global safety boundaries.
