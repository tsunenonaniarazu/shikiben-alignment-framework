# 存在
　
```math
\text{存在} = \text{実在} + \text{象}
```

* **絶え間ない更新の方程式：クシュナー・ストラトノヴィッチ方程式（Kushner-Stratonovich Equation)**<br>
<br>実在の無限の生成変化と、次々に届く「一次情報 $`dy(t)`$」によって、システム内部の可能性（確率測度 $`\mathbb{P}_t`$）がリアルタイムに更新されていく動態は、確率論・制御理論における以下の更新方程式（フィルター方程式）によって表現される。

```math
\mathrm{d}\mathbb{P}_t = \underbrace{\mathcal{A}^* \mathbb{P}_t \,\mathrm{d}t}_{\text{実在自体の無限の生成変化}} + \underbrace{\mathcal{K}_t \left( \mathrm{d}y(t) - \hat{y}(t)\,\mathrm{d}t \right)}_{\text{一次情報による可能性（分布）のリアルタイム更新}}
```

|名称|定義|数理表現|数理的構造|補足|
| :--- | :--- | :--- | :--- | :--- |
|存在|あらゆる意味に於いて人と関りをもつ物事の総称|$\text{Ex} := (\text{Real}, \text{Sho})$|全体空間（実在と象の和集合）|人との関わり・認知の全域|
|実在|知覚される存在|$`\text{Real} := \mathcal{A}^* \mathbb{P}_t \,\mathrm{d}t`$|観測や知覚の有無にかかわらず、無限の因果演算子 $`\mathcal{A}^*`$ によって自律的に湧き上がり、無限に生成変化し続ける背景・深層の運動（実在そのものの生成項|知覚の背景・土台|
|象|想起され表れる存在|$`\text{Sho} := \mathcal{K}_t \left( \mathrm{d}y(t) - \hat{y}(t)\,\mathrm{d}t \right)`$|システムとの接触・更新によって意識のスクリーン上に立ち現れる一切の像|現象と表象の母体|
